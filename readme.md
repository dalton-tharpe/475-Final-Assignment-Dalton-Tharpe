I am very proud of this final and how it works. I started by gathering 140 images for my testing which took a long time. 
I gathered 70 real and 70 fake images of forests and decided that was enough for my project. I then divided them into their respective folders
one labeled test and one labeled train. I trained my model on the train folder which had 40 images in each of two folders inside labeled real and AI.
I then tested my images on 20 photos in the test folder with 2 more folders labeled real and AI. From here I took my other 20 images and put them
into my to_classify folder to run my code on them. These contained 10 real and 10 fake images with the fake images having very fake images as well
as some pretty real looking ones as well to really test the model. I was able to achieve a 100% correctness rate on my model with the images I had.
The coding part took the longest because I was struggling with getting the model to work with all the inputs and outputs it needed. I used ChatGPT to help 
get me where I needed to be and I am overall very happy with how it turned out. The biggest challenge I had was with inputs and outputs because as it turned
out I had a python version that was not supportive of some of the imports I was using and required different information than I could give it. I had to take a few hours deciphering which one I needed and then installing and reinstalling python a few times to fix it. After that it was smooth sailing and I enjoyed doing this a lot.
